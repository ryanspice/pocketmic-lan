QR pairing

The release notes describe QR pairing and the Windows receiver’s QR display, reducing manual entry of connection details.

Pairing-key storage on Android

The release adds encrypted Android storage for pairing keys. Keep the pairing key and QR code private regardless of how they are stored.

Streaming and lifecycle work

The release points to the changelog for its streaming and lifecycle fixes. This page does not reinterpret those implementation changes as a universal end-to-end performance benchmark.

What this release does not establish.

It does not provide a production-signed Android APK or a Windows installer. Its notes explicitly leave end-to-end hardware, Wi-Fi, Windows audio-driver, and VB-CABLE acceptance to physical-device testing.

No date is promised here for a bundled PocketMic virtual microphone driver, store distribution, automatic updates, or other operating systems.
