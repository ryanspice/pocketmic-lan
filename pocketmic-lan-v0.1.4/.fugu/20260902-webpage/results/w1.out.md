## 3. PERFORMANCE FACTS
- Sample rate: 48,000 Hz, mono, signed PCM16 little-endian — PROTOCOL.md:7-9
- Packet size: 480 samples / 960 plaintext bytes per packet — PROTOCOL.md:10
- Packet frequency: 100 packets per second — PROTOCOL.md:11
- Raw audio bandwidth: 768 kbit/s — PROTOCOL.md:12
- Total datagram length: exactly 1000 bytes — PROTOCOL.md:30
- Prebuffer: Windows starts playback after a 40 ms prebuffer — README.md:132; PERFORMANCE_AUDIT.md:22
- Latency trimming: buffered latency trimmed above 140 ms — README.md:134; PERFORMANCE_AUDIT.md:25
- Meter rate: input meter updates at 10 Hz — README.md:130; PERFORMANCE_AUDIT.md:10
- Buffer reuse: Android encryption/header/packet buffers reused in the 100-packet/s hot path — README.md:128; PERFORMANCE_AUDIT.md:9
- Loss concealment: gaps of 1–10 packets get 10 ms silence frames (at most 100 ms) — PROTOCOL.md:49; README.md:133
- Recorder floor: Android minimum or four-packet floor, not an unconditional 80 ms floor — README.md:131
## 4. SECURITY FACTS
- Key derivation: SHA-256(UTF-8(pairing key)) — README.md:142; PROTOCOL.md:34
- Cipher: AES-256-GCM — README.md:143; PROTOCOL.md:35
- Nonce: random 64-bit stream session + unsigned 32-bit sequence — README.md:144; PROTOCOL.md:36
- Authenticated data: complete 24-byte protocol header — README.md:145; PROTOCOL.md:37
- Authentication tag: 128 bits — PROTOCOL.md:38
- Android backup: disabled — README.md:146
- Network scope: trusted private LAN only — README.md:147
- Control channel: HMAC-SHA256 over 224-byte framing; key HMAC-SHA256(SHA-256(pairing key), "pocketmic-control-v1"), domain-separated — PROTOCOL.md:68-70
- Sequence reuse: every sequence used at most once per session; reconnect does not reset the counter — PROTOCOL.md:40-42
- Boundary warning: "Do not port-forward the receiver. Encryption protects packet contents and integrity; it does not make this a hardened internet voice service." — README.md:149
## 5. HOW IT WORKS (end-to-end flow)
1. Extract PocketMicReceiver-win-x64.zip and run PocketMicReceiver.exe — README.md:80
2. Copy the preferred IPv4 address shown by the receiver — README.md:81
3. Enter it in PocketMic on Android — README.md:82
4. Enter the same pairing key on both devices — README.md:83
5. Choose speakers/headphones for a test, or CABLE Input for virtual-microphone routing — README.md:84
6. Start the Windows receiver — README.md:85
7. Tap Start microphone on the phone — README.md:86
