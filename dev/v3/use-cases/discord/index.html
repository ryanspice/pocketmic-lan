The route, step by step.

  1. Connect PocketMic.
    Install both apps, pair on the same private network, and confirm the receiver gets audio.
  2. Set the receiver output.
    With VB-CABLE installed, choose CABLE Input as the PocketMic receiver’s playback destination.
  3. Choose the Discord microphone.
    In Discord’s Voice & Video settings, select CABLE Output as the input device. Keep the output device on your normal headphones.
  4. Run the mic test.
    Use Discord’s Mic Test to listen to the result before you join voice chat. This checks the destination app, not just the PocketMic input meter.
Know the boundary.

This is a networked mic, not a zero-latency gaming accessory. Device processing and buffering affect the result. The PocketMic hop stays local; Discord still handles your online call.

Before you commit.

Can I use this for in-game voice chat too?

Use a game’s microphone selector to choose the VB-CABLE recording endpoint where supported. App-specific input support varies; test the actual game rather than assume a universal route.

What do I download?

The Android debug-signed APK and the Windows receiver ZIP from the same PocketMic release. VB-CABLE is a separate download. See the exact files.

What should I do if there is no sound?

Check the path in order: phone capture, receiver packets, receiver output, then your app’s microphone. Use the troubleshooting guide.
