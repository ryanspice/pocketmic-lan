Install the phone app.

  1. Download the debug APK on your phone.
    The installable asset is PocketMic-v0.1.4-debug.apk. The separate release-unsigned.apk is not the consumer installation path.
  2. Review the source and Android’s installation prompt.
    Only allow installation from a source you trust. Do not disable Play Protect or ignore an unexpected warning. This is an early, debug-signed build.
  3. Open PocketMic and allow microphone access when requested.
    Install and open the Windows receiver next. Pair only on your trusted private network.
Check before you trust.

The v0.1.4 release does not include a production-signed Android APK. A checksum helps confirm the downloaded file matches the release; it does not replace publisher trust or a security review.

Installing from your PC?

With Android platform tools and an authorised device already configured, use the published APK:

adb install -r .\PocketMic-v0.1.4-debug.apk

Verify the downloaded file.

Compare a SHA-256 hash with the value below or the release’s SHA256SUMS.txt (opens in a new tab).

Get-FileHash .\PocketMic-v0.1.4-debug.apk -Algorithm SHA256
