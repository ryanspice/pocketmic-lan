Download / Windows

Your PC is
the receiver.

Run PocketMic Receiver on Windows to receive encrypted audio from your Android phone and choose its playback destination.

Download Windows ZIP

68.1 MB · v0.1.4 · Self-contained x64 ZIP

Start the PC receiver.

  1. Download and extract the ZIP.
    Use PocketMicReceiver-win-x64.zip from the same release as the Android app.
  2. Run PocketMicReceiver.exe.
    The package is self-contained; the release does not require a separate .NET runtime installation. Review any Windows publisher or security warnings before proceeding.
  3. Use a trusted private network.
    Allow only the documented PocketMic traffic on your Private firewall profile. Do not switch off the firewall or port-forward the receiver.
  4. Pair the Android app and choose an output.
    For a first direct listening test, use headphones. To expose the audio as a microphone input in another app, install VB-CABLE and choose CABLE Input.
This is a ZIP, not an installer.

Extract the full package before running the executable. Automatic updates and a bundled virtual microphone driver are not part of this download.

Verify the downloaded file.

Compare a SHA-256 hash with the value below or the release’s SHA256SUMS.txt (opens in a new tab).

Get-FileHash .\PocketMicReceiver-win-x64.zip -Algorithm SHA256
