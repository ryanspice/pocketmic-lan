Quick fit check

Have these
within reach.

Android 8+ phone. Windows 11 x64 PC. Both devices on the same trusted private network.

A little setup is part of the deal.

You’ll install an Android APK, extract the Windows receiver, and install VB-CABLE separately for app microphone routing. The Android download is debug-signed, not a production store build.

Using a work-managed device? Check installation permissions first. Need iPhone, macOS, or Linux? Those builds are not offered here.
